# Asset licence

The MIT licence in `LICENSE` covers the Lua source, scripts and text files in
this repository. This file covers the art: everything under `42/media/models_X/`, `42/media/textures/`, `42/media/sound/`, and the `icon.png` image.

You are welcome to:

- use and modify these assets in Project Zomboid mods, with credit and a link
  back to this repository;
- study them, take them apart, and learn from how they were made.

Please don't:

- reupload this mod wholesale, to the Workshop or anywhere else — release links
  belong in one place so fixes actually reach players;
- sell these assets or include them in paid products.

Models and textures began as [Meshy](https://www.meshy.ai/) generations and were
substantially reworked — retopology, rigging to the game's own skeletons,
texture repair — before shipping.

Sound clips are derived from CC0 recordings on Freesound — `CREDITS.md` lists
every source. The originals remain CC0 where they came from; this notice covers
only the edited clips as shipped.

If you want to do something these terms don't cover, open an issue and ask —
the answer is probably yes.
